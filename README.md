# NikNakk Threshold

## How do I install these formulae?

`brew install niknakk/threshold/<formula>`

Or `brew tap niknakk/threshold` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "niknakk/threshold"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
